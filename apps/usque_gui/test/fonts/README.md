# Linux golden font fixtures

These fonts are test fixtures, loaded explicitly by
`test/support/linux_golden_support.dart`. They are not production assets and are
not listed in `pubspec.yaml`. The loader checks the SHA-256 of every fixture
before registering its actual font family; it never resolves system fonts.
The existing bundled Latin and icon fonts remain the primary fonts.

The source fonts use SIL Open Font License 1.1. The accompanying license texts are
`NotoSansCJK-LICENSE` and `NotoNaskhArabic-OFL.txt`. The CJK font metadata retains
the original copyright, family, version and license entries. Neither license
declares a Reserved Font Name.

## Unavailable-family simulation

The pinned Flutter engine substitutes its built-in `FlutterTest` face when a
test requests an unknown family. That face maps some Chinese characters,
including `本`, `中` and `文`, to a solid square. Thus the production fallback
list's unavailable Windows/macOS families can intercept those characters before
the real Noto fallback gets a chance to render them.

`MissingFamily.ttf` is an original test-only placeholder, generated by
`build_missing_family.py` with FontTools 4.60.1. Its Unicode character map is
empty and its only glyph is an empty `.notdef`. The loader registers this empty
face for each production fallback family not present in the pinned fixture.
This models an unavailable family without changing the production styles or
registering Noto glyphs under a different family's name. Real Noto families and
bundled primary fonts are never replaced. This affects only the Linux golden
test isolate, not other tests, Windows baselines or production font resolution.

Reproduce it from the repository root, without network access:

```shell
python apps/usque_gui/test/fonts/build_missing_family.py \
  --output /path/to/reproduced/MissingFamily.ttf
```

## Reproducing the CJK subsets

`cjk-codepoints.txt` fixes the corpus used for both weights. It contains the
sorted Unicode codepoints present in `lib/**/*.dart` and `test/**/*.dart` when
the fixtures were introduced, plus printable ASCII. FontTools keeps the glyphs
supported by the CJK source font and their layout dependencies; Arabic and other
unsupported characters in the corpus do not create replacement glyphs.

The Profiles scene fixtures extend that corpus with the current Dart sources,
including all 21 scenario translations and country labels. Both regenerated
weights cover all 2,270 corpus codepoints supported by the pinned originals;
the existing Arabic/Persian fonts retain their full shaping coverage.

Use FontTools **4.60.1** in a temporary environment, download the two originals
above into a temporary source directory, and run from the repository root:

```shell
python apps/usque_gui/test/fonts/subset_cjk.py /path/to/original/fonts \
  --output-directory /path/to/reproduced/subsets
```

The script verifies each original hash before use, retains the original font
timestamps, names, licenses, hinting and layout features, and prints the output
hashes. Compare those hashes with the table above. Normal tests require neither
FontTools nor network access.

When a new golden needs a CJK character outside the fixed corpus, append its
hexadecimal codepoint to `cjk-codepoints.txt` in numeric order, regenerate both
weights using this script, update the hashes in this document and the loader,
and visually review every affected Linux golden. Do not regenerate Windows
baselines or rename these families to Windows font names.
