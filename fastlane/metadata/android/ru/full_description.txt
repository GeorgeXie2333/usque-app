Usque — неофициальный клиент, совместимый с сервисами Cloudflare® WARP® для Android / Android TV (есть также сборки для Windows). Он совмещает системный VPN, SOCKS5 и HTTP-прокси в нативном интерфейсе Flutter; сеть обеспечивает движок MASQUE на Rust. Требуется Android 8.0 (API 26) или новее.

<strong>Варианты подключения (используют одно подключение WARP, могут работать одновременно)</strong>
<ul>
<li><b>VPN/TUN</b>: направлять системный трафик через туннель с правилами обхода и правилами по приложениям</li>
<li><b>SOCKS5</b>: локальный прокси TCP/UDP для совместимых приложений; по умолчанию удалённый DNS</li>
<li><b>HTTP-прокси</b>: локальный HTTP-прокси, включая HTTPS через CONNECT</li>
</ul>

<strong>Возможности</strong>
<ul>
<li>VPN с полным туннелем, DNS внутри туннеля, Kill Switch, доступ к локальной сети</li>
<li>Правила DIRECT/REJECT/PROXY с блокировкой рекламы; правила рекламы обновляются автоматически во время работы приложения</li>
<li>Необязательный цепной прокси: OpenVPN, WireGuard, WARP via WireGuard, VPN Gate, HTTP, SOCKS5</li>
<li>Автоматическое подключение HTTP/3 с откатом на HTTP/2; попытки через IPv4 и IPv6</li>
<li>Пользовательский DNS выхода WARP: обычный DNS, DoH или DoT</li>
<li>Необязательная прямая маршрутизация по странам; данные GeoIP и GeoSite скачиваются отдельно</li>
<li>Локальная диагностика сети и страница качества: задержка, потеря пакетов, очереди, тенденции за 60 секунд</li>
<li>Плитка быстрых настроек, ярлыки запуска, восстановление после загрузки, навигация на телевизоре</li>
<li>Прокси по приложениям; невыбранные приложения можно блокировать вместо обхода туннеля</li>
<li>Двадцать один язык, светлая и тёмная темы</li>
</ul>

<strong>Конфиденциальность</strong>
<ul>
<li>Открытый ключ сервера WARP должен совпадать с зарегистрированным; проверку нельзя пропустить</li>
<li>Учётные данные хранятся в Android Keystore; VPN работает в отдельном процессе</li>
<li>Прокси по умолчанию слушают только loopback; поддерживается необязательная аутентификация по имени пользователя и паролю</li>
<li>Диагностика создаётся локально и обезличивается; аналитики использования и автоматической выгрузки нет</li>
<li>Журналы по умолчанию уровня INFO, хранение не более 7 дней или 20 МиБ</li>
</ul>
